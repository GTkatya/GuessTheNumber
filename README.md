## 1. Введение

Консольные игры являются простым, но эффективным способом изучения основ программирования и разработки программного обеспечения. В данном проекте была разработана консольная игра "Угадай число" на языке программирования Java, которая позволяет пользователю интерактивно взаимодействовать с программой, угадывая случайное число, загаданное компьютером. Игра была создана с целью демонстрации базовых концепций программирования, таких как работа с вводом-выводом, циклами, условными операторами, обработкой исключений и хранением данных.

Проект начался с простой версии игры, где пользователь пытался угадать число в заданном диапазоне, получая подсказки. По мере развития проекта были добавлены дополнительные функции, такие как уровни сложности, ограничение по попыткам, подсказки с разницей и система рекордов. Эти улучшения сделали игру более интересной и функциональной, а также расширили её образовательную ценность.

Целью данного отчета является описание процесса разработки, анализа кода, а также подведение итогов работы над проектом. Отчет поможет понять, как были реализованы ключевые функции игры, какие трудности возникли и как они были решены.

## 2. Основная часть

### 2.1. Цели и задачи проекта

Цель проекта заключалась в создании простой, но увлекательной консольной игры, которая демонстрировала бы базовые и продвинутые возможности языка Java. Среди конкретных задач были:

- Разработка базовой версии игры, где пользователь должен угадать случайное число.
- Добавление интерактивных элементов, таких как выбор уровня сложности и подсказки.
- Реализация системы ограничений по попыткам и подсчета рекордов.
- Обеспечение корректной обработки ошибок ввода и удобного интерфейса для пользователя.
- Документирование процесса разработки и анализа кода.

### 2.2. Описание игры

Игра "Угадай число" представляет собой консольное приложение, в котором компьютер загадывает случайное число в заданном диапазоне (например, от 1 до 50, 100 или 200, в зависимости от уровня сложности). Пользователь вводит свои предположения, а программа сообщает, больше или меньше введенное число по сравнению с загаданным. После каждой попытки пользователь получает дополнительную информацию: на сколько единиц он ошибся.

Игра включает следующие особенности:

- Три уровня сложности: легкий (1-50), средний (1-100) и сложный (1-200).
- Ограниченное число попыток для каждого уровня (15, 10 и 8 соответственно).
- Подсказки с указанием разницы между введенным и загаданным числом.
- Система рекордов, хранящая лучшее количество попыток для каждого уровня.
- Возможность сыграть заново или выйти из игры.

### 2.3. Структура и реализация кода

Код написан на Java и состоит из одного класса `GuessTheNumber`. Основные компоненты включают:

- **Импорт библиотек**: `Random` для генерации случайных чисел, `Scanner` для чтения ввода пользователя, `HashMap` для хранения рекордов.
- **Переменные и константы**: Определены максимальные значения для каждого уровня сложности и количество попыток.
- **Методы**:
  - `start()`: Начало игры, где пользователь выбирает уровень сложности.
  - `playGame(String, int, int)`: Основной игровой цикл, где происходит угадывание числа.
  - `updateBestScore(String, int)`: Обновление рекордов.
  - `showBestScores()`: Показ лучших результатов.

Пример ключевого фрагмента кода (проверка ввода и подсказки):

```java
while (attempts < maxAttempts) {
    System.out.print("Введи число: ");
    try {
        int userGuess = Integer.parseInt(scanner.nextLine());
        attempts++;

        if (userGuess < 1 || userGuess > maxRange) {
            System.out.println("Пожалуйста, введи число в диапазоне от 1 до " + maxRange + "!");
            continue;
        }

        int difference = Math.abs(userGuess - targetNumber);
        if (userGuess < targetNumber) {
            System.out.println("Слишком низко! Ты был на " + difference + " единиц ниже.");
        } else if (userGuess > targetNumber) {
            System.out.println("Слишком высоко! Ты был на " + difference + " единиц выше.");
        } else {
            System.out.println("\nПоздравляю! Ты угадал число " + targetNumber + " за " + attempts + " попыток!");
            won = true;
            updateBestScore(difficulty, attempts);
            break;
        }
    } catch (NumberFormatException e) {
        System.out.println("Пожалуйста, введи корректное число!");
    }
}
```

Этот фрагмент демонстрирует обработку ввода, проверку границ, подсчет попыток и выдачу подсказок.

Изначально игра была простой, но по мере развития были добавлены следующие улучшения:

- **Подсказки с разницей**: Сделали игру более информативной и полезной для обучения.
- **Рекорды**: Мотивация для игроков улучшать свои результаты.
- **Обработка ошибок**: Улучшенная проверка ввода для предотвращения сбоев.

Эти изменения сделали игру более сложной, но сохранили её доступность и интерактивность.
